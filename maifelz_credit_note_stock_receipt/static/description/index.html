Automated Warehouse Logistics

Maifelz Credit Note Stock Receipt

Seamlessly bridge Accounting and Inventory in Odoo. Automatically create and confirm incoming Stock Receipts directly upon posting Customer Credit Notes with zero manual coordination.

Odoo 19.0 Ready Community Enterprise Odoo.sh & Cloud
Why Businesses Need This

Solving the Return Bottleneck

Without This Module

  • Finance drafts credit notes with no direct link to warehouse pickings.
  • Warehouse teams must be manually notified via phone/email to expect returns.
  • Stock counts become inaccurate because return receipts are forgotten or delayed.
  • Double data-entry creates costly inventory valuation discrepancies.

With Maifelz Module

  • Select the destination return warehouse directly on the Customer Credit Note.
  • Confirmed Incoming Shipment (Stock Picking) is generated automatically on Post.
  • Warehouse team receives real-time notice with pre-filled storable goods.
  • Instant one-click access between Credit Note and Stock Moves via Smart Button.
Core Functionality

Key Feature Highlights

Return Warehouse Selection

Designate the specific receiving warehouse right on Customer Credit Notes (out_refund) before posting.

Automatic Picking Creation

Posting triggers auto-creation of a confirmed incoming shipment picking with all storable lines assigned to the chosen warehouse.

Direct Smart Button

A dedicated Receipts smart button on the credit note header allows 1-click navigation to inspect and validate the picking.

Clean Standard Logic

Built with native Odoo ORM methods. Fully compatible with multi-company environments, standard valuation, and Odoo.sh deployments.

Step-by-Step Workflow

How It Works in 3 Steps

1

Select Return Warehouse

Draft a Customer Credit Note (out_refund) and pick the destination warehouse from the "Return Warehouse" dropdown.

2

Post Credit Note

Click Post. The module automatically generates a confirmed incoming shipment picking (stock.picking) with all storable products.

3

Validate Return Receipts

Click the Receipts smart button on the credit note header to open the stock picking, inspect quantities, and validate receipt into inventory.
