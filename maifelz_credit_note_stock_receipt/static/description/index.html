How It Works in 3 Simple Steps

Bridge financial credit notes with physical warehouse receipts in a fully automated, synchronized cycle.

1

Select Return Warehouse

When creating or editing a Customer Credit Note (out_refund), choose the destination Return Warehouse from the dropdown on the form.

2

Post Credit Note

Click Post. The module immediately generates a confirmed Incoming Shipment (Stock Picking) with all storable lines assigned to the chosen warehouse.

3

Validate Return Receipts

Click the dedicated Receipts smart button to navigate directly to the stock picking, receive incoming products, and update inventory valuations.
